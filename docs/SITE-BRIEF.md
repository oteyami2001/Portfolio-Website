# Original portfolio brief

## Reference analysis
Public site: https://www.willacyknowles.com. Observed content patterns: branded OS-like intro, large typography and narrative hero, story section, career timeline, three-pillar operating model, featured work, interactive node graph, assistant interface. Exact animation internals, frameworks and backend services were not verified.

## Creative direction
Create an original cloud-control-plane aesthetic: deep navy, soft cyan, warm amber accent, subtle animated infrastructure topology, clean typography. Avoid using KnowlesOS, its copy, logos or its personal story.

## Site sections
1. Hero: Cloud infrastructure that is secure, scalable and built to last; CTAs View Projects / Contact.
2. About: concise experience and specialties.
3. Expertise: AWS, Azure, OCI, Oracle, Terraform, DevOps, Security.
4. Timeline: professional and educational milestones, sourced from resume.
5. Featured projects: AWS migration and Azure orchestration, each with challenge, architecture, actions, results, GitHub link.
6. Cloud topology: interactive nodes for Networking, Compute, Databases, Security, Observability, Automation.
7. Certifications and education.
8. Contact: validated links and an operational form only after endpoint is configured.
9. Optional AI assistant: portfolio-only answers grounded in authored content, with disclosure and safeguards.

## Design acceptance criteria
Mobile 320px+; WCAG AA contrast; keyboard graph alternatives; fast LCP; motion disabled for reduced-motion; zero horizontal overflow; accessible focus states; descriptive metadata and OG card; no unverifiable performance statistics.

## Build phases
1. Theme, global layout, hero, responsive nav.
2. About, expertise, timeline, certifications.
3. Project case studies and GitHub links.
4. Interactive topology and animations.
5. Optional AI assistant/contact backend.
6. Accessibility, SEO, tests, deploy.
