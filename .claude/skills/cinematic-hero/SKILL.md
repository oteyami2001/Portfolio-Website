# Cinematic cloud hero

## Instructions
Create an accessible landing hero with subtle SVG cloud-network motion, clear headline, short professional value proposition and two working CTA links. Intro must be skippable and respect reduced motion. Avoid excessive WebGL and blocking loaders.

## Workflow
1. Inspect existing project files and dependencies before editing.
2. Propose a minimal component plan consistent with `CLAUDE.md`.
3. Implement production-quality TypeScript/React with reusable components.
4. Add tests or manual verification steps and check mobile + keyboard usage.
5. Report changed files, verification performed and outstanding configuration.
