# Optional portfolio assistant

## Instructions
Provide a safe architecture for an optional portfolio FAQ assistant. First build a static FAQ or search. For live AI, use a server endpoint with secrets in environment variables, rate limits, minimal logging, grounded portfolio content, and transparent disclosure. Never claim an AI service is live until configured and tested.

## Workflow
1. Inspect existing project files and dependencies before editing.
2. Propose a minimal component plan consistent with `CLAUDE.md`.
3. Implement production-quality TypeScript/React with reusable components.
4. Add tests or manual verification steps and check mobile + keyboard usage.
5. Report changed files, verification performed and outstanding configuration.
